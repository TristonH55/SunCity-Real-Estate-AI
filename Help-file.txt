1️⃣ Check the existing user

IN vscode terminal Run this in Neon:

SELECT id, email, role, approved, "companyName"
FROM "User"
WHERE email = 'admin@suncityhotwater.com.au';

You will likely see something like:

admin@suncityhotwater.com.au | insurer | false

or similar.

2️⃣ Instead of inserting — update the user to admin

Since the email already exists, the correct fix is:

UPDATE "User"
SET
  role = 'admin',
  approved = true,
  "companyName" = 'SunCity Hot Water'
WHERE email = 'admin@suncityhotwater.com.au';
